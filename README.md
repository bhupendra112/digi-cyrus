# digi-cyrus

Engineering Digital Growth — Website development, app development & digital marketing for Indian startups and brands.

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
